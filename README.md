# Delivery Run Game

Juego en 2D desarrollado en Unity como proyecto de aprendizaje.

## Objetivo del proyecto

Este juego se implementó para practicar y comprender:

- Colisiones entre objetos.
- Triggers para detectar interacciones.
- Mecánicas de power-ups que aumentan la velocidad.
- Movimiento y control básico de un personaje en un entorno 2D.

## Controles

- `W`: mover hacia arriba.
- `A`: mover hacia la izquierda.
- `S`: mover hacia abajo.
- `D`: mover hacia la derecha.

## English

# Delivery Run Game

A 2D game developed in Unity as a learning project.

## Project goal

This game was implemented to practice and understand:

- Collisions between objects.
- Triggers for detecting interactions.
- Speed power-up mechanics.
- Basic character movement and control in a 2D environment.

## Controls

- `W`: move up.
- `A`: move left.
- `S`: move down.
- `D`: move right.
